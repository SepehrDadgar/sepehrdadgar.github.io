what do these symbols mean?
differential pair
two matched transistors whose sources are joined and fed by one current source, the tail. the circuit amplifies the difference between the two gate voltages.
Vid, Vcm
differential input V1 − V2 (the signal), and common-mode input (V1 + V2)/2 (the average level both inputs sit at).
Itail
the fixed current of the tail source. it is shared: I1 + I2 = Itail.
β = k′·W/L
the transistor’s strength: ID = ½·β·Vov² in saturation.
ICMR
input common-mode range: the Vcm values for which every transistor stays in saturation and the amplifier keeps its gain.
Vov,tail
the overdrive of the tail transistor. its drain (the pair’s common source node) must stay at least this high for the tail to remain a good current source.
square-law model with λ = 0 for the pair, an ideal current-setting tail, resistor loads, and a differential input. the headroom lines assume the currents stay at the values set above; in a real circuit the current starts to collapse once something leaves saturation.
